# Premium Fresh Meat - Full-Stack Python Website (With Wishlist)

## How to Run in VS Code:
1. Extract this ZIP folder and open the `premium_meat_store` folder in VS Code.
2. Open the VS Code Terminal (`Ctrl + ~`).
3. Install Flask:
   pip install -r requirements.txt
4. Run the application:
   python app.py
5. Open your browser and visit:
   http://127.0.0.1:5000
