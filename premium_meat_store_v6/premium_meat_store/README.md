# Premium Fresh Meat - Full-Stack Python Website (v4)

## How to Run:
1. Extract this ZIP and navigate into the inner `premium_meat_store` folder:
   cd premium_meat_store
2. Install dependencies:
   pip install -r requirements.txt
3. Start the server:
   python app.py
4. Visit http://127.0.0.1:5000 in your browser.
